# ホワイトハッカーとサイバーインテリジェンス実践体系

攻撃者の行動を理解し、検証・検知・対応・経営判断につなげるための実践的な日本語セキュリティ書籍です。

このリポジトリは現在、出版基盤の初期構築中です。作業状況は [Issue #1](https://github.com/itdojp/white-hat-cyber-intelligence-book/issues/1) を参照してください。

## 安全上の原則

掲載する評価・演習は、明示的に許可された自己所有環境、隔離ラボ、合成データだけを対象とします。実在する第三者システムへのスキャン、認証試行、アクセスを目的としません。
